## C) JSON log schema (version 1.0.0)

Each attempt produces a record with the following fields:

* `schema_version: str` — **"1.0.0"**
* `task_id: str` — e.g., `CF1285A` or `BIGOBENCH_1718`
* `seed: int` — one of the seeds in `configs/seeds.txt`
* `replan_idx: int` — 0‑based attempt index within a task/seed (≤ 2 for cap=3)
* `input_sizes: List[int]` — monotone sizes used for profiling
* `runtime_ms: List[float]` — wall‑clock or CPU time per input size
* `peak_memory_mb: List[float]` — peak RSS per input size
* `fit: { slope: float, r2: float, class: str }` — curve‑fit summary used for complexity class
* `verdict: str` — `accept | replan | reject` (analyst decision)
* `pass: bool` — unit tests passed
* `tle: bool` — time limit exceeded flag
* `mle: bool` — memory limit exceeded flag
* `timestamps: { started_utc: str, finished_utc: str }` — ISO‑8601

**Example**

```json
{
  "schema_version": "1.0.0",
  "task_id": "CF1285A",
  "seed": 42,
  "replan_idx": 0,
  "input_sizes": [1000, 5000, 10000, 50000, 100000],
  "runtime_ms": [1.3, 2.6, 5.1, 25.9, 51.7],
  "peak_memory_mb": [8.7, 8.7, 8.8, 9.1, 9.4],
  "fit": { "slope": 1.01, "r2": 0.93, "class": "O(n)" },
  "verdict": "accept",
  "pass": true,
  "tle": false,
  "mle": false,
  "timestamps": { "started_utc": "2025-08-24T19:20:04Z", "finished_utc": "2025-08-24T19:20:05Z" }
}
```

## D) Figures: regeneration contract

* All figure scripts live in `figures/` and write `figures/fig_k.png` by default.
* Some scripts (e.g., **Figure 1**) currently read a fixed input filename. If so, create a symlink to your latest results before running (see `REPRODUCIBILITY.md`, §4.1).
* For reviewers: pre‑rendered PNGs are provided for quick inspection; the authoritative plots are those re‑generated from your local logs.

## E) Integrity verification (hashes & sizes)

Compute and record SHA256 + byte size for shipped artifacts.

```bash
# Linux
sha256sum figures/fig_1.png figures/fig_2.png figures/fig_3.png figures/fig_4.png \
          configs/bigobench.json configs/codeforces.json configs/seeds.txt
stat -c%s figures/fig_1.png

# macOS
shasum -a 256 figures/fig_1.png figures/fig_2.png figures/fig_3.png figures/fig_4.png \
             configs/bigobench.json configs/codeforces.json configs/seeds.txt
stat -f%z figures/fig_1.png
```

Paste values into the table in §A.
